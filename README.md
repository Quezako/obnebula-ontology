# Obnebula Ontology

Maquette statique (Vue 3) pour gérer une ontologie de groupes et tags avec drag & drop.

## Pré-requis

- Node.js 18+

## Installation

```bash
npm install
```

## Lancer en dev

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Tout est en mémoire (pas de base de données).
- Drag & drop entre groupes, pas dans les tags.
